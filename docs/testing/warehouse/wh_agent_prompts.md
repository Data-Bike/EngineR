# 100 промптов управляющего складом «ТЕСТ»

Сценарий выполняется агентом последовательно, сверху вниз, **исключительно
через EngineR MCP** (`http://localhost:8020/mcp`, JSON-RPC `tools/call`).
Агент хранит `public_id` созданных объектов и использует их в последующих
промптах. Нумерация и коды объектов совпадают с промптами — коды уникальны
внутри прогона (суффикс `MGR` + run nonce при повторных прогонах).

Доменная схема (ревизия ≥62): `wh_warehouse`, `wh_zone`, `wh_product`,
`wh_stock`, `wh_inbound`, `wh_outbound`, `wh_inventory`, `wh_supplier`,
`wh_client`, `wh_contractor`, `wh_cargo`, `wh_waybill`, `wh_payment`,
`wh_expense`, `wh_hold` + `person`, `legal_entity`, `document`.
